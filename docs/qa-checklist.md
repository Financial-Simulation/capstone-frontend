# 화면 점검 목록

실제 v1.7 백엔드로 화면을 눌러 보며 확인하는 목록이에요. 발표 리허설 전에 한 번 다 보고, PR 전에는 바꾼 부분만 봐요.
숫자는 팀 정답 파일과 같아야 해요 (같은 seed라서 백엔드가 켜져 있으면 정확히 같은 숫자).

## 준비

- [ ] 백엔드는 GitHub main(v1.7, 받아 둔 폴더면 `git pull`) → `./gradlew bootRun`, 프론트 `npm run dev` (발표 리허설은 `npm run build && npm start`, README '발표 데모')
- [ ] `/dev` → API 점검 `전부 실행`: 17개 모두 기대대로 (백엔드가 v1.7인지)
- [ ] `/dev` → 정답 파일 대조 `전부 대조`: `같음 55 / 55`
- [ ] 휴대폰 폭: Chrome 개발자 도구(⌥⌘I) → 기기 모드(⇧⌘M) → 390 × 844

## 00 시작

- [ ] 처음 들어오면 '시뮬레이션 시작하기' · '예시 결과 보기'
- [ ] 입력이 남아 있으면 '이어서 할까요?'(이어서 하기 / 새로 시작), 기준 달이 지났으면 '기준 달을 이번 달로 바꿀까요?'

## 01-1 나와 소득/지출

- [ ] 빈 채로 '다음' → 빈 칸이 빨갛게, 첫 칸으로 이동
- [ ] 칸 아래 범위 안내(19~39세 · 0~10년 · 1만~3,000만 원)와 범위 밖 값의 문장
- [ ] '더 정확하게 넣기': 세전 연봉이 월 실수령액 × 12보다 작으면 세전 연봉 칸 아래 오류 (접혀 있으면 펼쳐서 그 칸으로)
- [ ] '그중 월세'가 고정지출보다 크면 그 칸 아래 오류
- [ ] 지출이 소득 이상이면 경고 모달 ('수정하기' / '그대로 진행')

## 01-2 자산/대출/저축

- [ ] 대출 카드: 종류를 고르면 평균 금리, 칸이 다 차면 월 상환액 미리보기
- [ ] 매달 남는 돈 · 청년미래적금 안내가 입력하는 대로 바뀜
- [ ] 매달 모자라면 경고 모달

## 02 목표 · 03 시나리오

- [ ] 목표 시점은 기준 연월부터 1~10년만 고를 수 있음, 이미 목표 이상이면 안내 모달
- [ ] 추가 시나리오 5종: 켜면 '언제'와 기본 금액. 이직은 '−90~+200%, 기본 +10%' · '0~24개월, 기본 2개월'

## 04 결과

- [ ] 계산 중 → 결과 (5초가 넘으면 '평소보다 오래 걸리고 있어요')
- [ ] 예시 S1과 같은 입력이면 58.0%, 첫 문장에 4,440만 원
- [ ] 배치 (조민석 배치안 11/18): 결론 → [그래프 | 계획 바꿔 보기] (넓은 화면 두 칸, 휴대폰은 위아래) → 조심할 점(작은 줄) → 상품별로 나눠 보기(원그래프 3개) → 받을 수 있는 혜택(카드 두 줄) → 혜택 질문(접힘) → 숫자 더 보기(접힘)
- [ ] 그래프: 누르거나 화살표 키로 달 옮기기, '표로 보기'
- [ ] 그래프: 날짜가 다른 이벤트는 각 번호와 실제 이름으로 구분되고, 같은 달에 여러 이벤트가 있으면 하나의 번호에 이름을 함께 표시함
- [ ] 그래프 위 [전체 범위 · 최상 · 중간 · 최악]: 같은 그래프에 한 미래가 한 달씩 그려짐 · 큰 사건 배너 · 재생/일시정지 · 4/8/16개월/초 · 달 옮기기 막대 · 변수 칸 · 계좌 줄 · '지금까지 일어난 일'(접힘) · '전체 범위'로 돌아오기
- [ ] 계획 바꿔 보기: 막대를 끌면 0.3초 뒤 결론 · 그래프 · 조심할 점 · 혜택이 바뀜, 결론에 '바꾼 계획 · 지금 계획은 X%', 그래프에 지금 계획 회색 점선, 위쪽 '지금 X% → 바꾼 계획 Y%'
- [ ] 계획 바꿔 보기: '이렇게 하면 좋아져요' 칩 → 그것만 바꾼 막대 (칩의 %와 바뀐 결론의 %가 같음, 예: S1 변동지출 줄이기 70.5%) · '지금 계획으로 되돌리기'
- [ ] 계획 바꿔 보기: 막대를 바꾼 뒤 [최악] → 바꾼 계획의 미래가 나옴
- [ ] 계획 바꿔 보기: ‘시나리오 바꿔 보기’에서 독립·전세 이사·결혼 비용·이직·자동차를 켜면 시점과 서버 기본값이 열림. 여러 일을 바꿔 비교해도 저장한 계획이 회색 점선으로 남고, 자동차는 차 값과 월 유지비가 같이 반영됨. 이사를 추가하거나 옮기면 이사 후 현금이 가장 적은 달도 표시됨. 다시 열거나 새로고침해도 저장한 입력은 그대로.
- [ ] 시나리오 단계에서 저장한 일은 ‘시나리오 바꿔 보기’를 처음 열 때 체크되어 있고, 저장한 날짜와 금액이 그대로 표시됨. 금액 칸은 넓은 화면에서도 한 줄에 하나씩 보이고, 저장한 입력 자체를 고치려면 ‘입력 수정’ 사용.
- [ ] 시나리오 비교 중 저축·지출·목표 막대나 상품 배분을 바꿔도 시나리오 표시와 저장한 계획 점선이 유지되고, 그래프와 이사 후 현금 요약은 두 변경을 함께 반영함. ‘시나리오 초기화’는 비교 전후 모두 체크·날짜·금액을 저장한 값으로 돌리고 비교 결과를 지우지만, 막대·배분 변경은 유지함.
- [ ] 시나리오를 추가해도 ‘앞으로 모을 돈’과 전체 범위·최상·중간·최악 버튼은 그대로임. 배분을 고른 뒤 재생하면 시나리오와 배분을 함께 반영한 경로가 나오고, 전체 범위로 돌아오면 저장한 계획 점선이 다시 보임. 월 저축액을 줄이면 추천 배분도 새 저축액 안에서 다시 계산함.
- [ ] 막대나 배분을 먼저 바꾼 뒤 시나리오를 추가하면 첫 계산부터 조정값을 반영함. 전체 범위에서 `/simulate`와 이사 현금 요약용 `/simulate/story`가 각각 한 번만 호출됨.
- [ ] 막대를 바꾼 뒤 계산 요청이 실패하면 ‘계산 중…’ 대신 ‘계산하지 못했어요’와 오류 안내가 나오고, 직전 그래프는 유지됨. 막대를 다시 바꿔 계산이 성공하면 오류가 사라짐.
- [ ] 상품별로 나눠 보기: 지금 배분과 두 추천을 보여 주고, 같은 배분이면 카드 하나에 기준을 함께 표시함. ‘이 배분으로 보기’를 누르면 결론과 그래프가 바뀜
- [ ] 계획 바꿔 보기: 배분 막대 3개(청년미래 · 청약 · 연금저축)는 월 저축액 안에서만 움직이고 남는 돈은 일반 적금. 청년미래 대상이 아니면 '대상 아님'으로 막힘
- [ ] 계획 바꿔 보기: '저축 · 지출 · 목표 바꾸기'(접힘) — 좋아져요 칩을 누르면 열림. 월 저축액을 줄이면 배분 막대가 남는 만큼으로 줄어듦
- [ ] 계획 담아 비교하기(접힘): 비교에 담기(새로고침해도 남음) · 담은 계획 비교 · 결론이 같은지
- [ ] 받을 수 있는 혜택(서버 /benefits): 받을 수 있어요(초록) → 확인해 보세요(노랑) → 일을 그만두면(파랑) → 못 받아요(회색, 이유) 순서, 정책 11개. S3(만 36세)는 청년미래 · 청년월세 '못 받아요' + 나이 이유
- [ ] 받을 수 있는 혜택: 들어오는 돈이 있는 정책(소득세 감면 · K-패스 · 청년월세)은 '받으면 66% → 73%'. 막대를 바꾸면 바꾼 계획 기준으로 다시 판정
- [ ] 혜택 카드의 ‘자세히 보기’는 Enter·Space·터치로 열리고 신청 방법·출처 등을 볼 수 있음. Esc나 닫기 버튼으로 닫으면 열기 버튼에 포커스가 돌아옴.
- [ ] 받을 수 있는 혜택: '알려 주면 정확해져요' 칩 → 아래 질문 칸이 열리고 그 질문으로 이동, 답하면 카드가 다시 판정됨 (T1: '중소기업인지' 예 → 소득세 감면 '받을 수 있어요')
- [ ] 못 받는 혜택: 다른 혜택과 같은 그리드에 회색 카드로 보이며, 카드 안에 서버가 준 이유가 클릭이나 호버 없이 표시됨.
- [ ] 혜택 오른쪽 위 ‘더 정확히 알고 싶다면 입력하기’ 버튼으로 질문을 열고 닫을 수 있음. 답은 새로고침해도 남음(simEligibility.v1), '답 모두 지우기'
- [ ] 상품별로 나눠 보기: 입력칸 없이 들어오자마자 '찾는 중…' → 원그래프 3개(지금 · 가능성 최고 · 세금·지원금 최고) · '이 배분으로 보기' → 위 배분 막대가 그 값으로 옮겨 가고 그쪽으로 이동 · '어떻게 골랐나요?'(접힘)
- [ ] 숫자 더 보기: 가능성 범위 · 1·3·5·10년 표 · 위험 카드 5장 · 세금 카드 5장 · 적금 깬 이유 · 바꿔 본 것 · 입력값과 가정
- [ ] 내 입력값과 적용 가정: 펼치면 근거 표
- [ ] 위쪽 · 아래쪽 '자세한 결과 보기 (PDF)' → 리포트 → '인쇄 · PDF로 저장' → 인쇄 창의 대상 'PDF로 저장' → 머리글 · 버튼 없이 A4로 나옴 (Chrome · Safari)
